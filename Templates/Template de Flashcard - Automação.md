# Flashcards - {{title}}

Formato de uma linha por cartão, no padrão `pergunta::resposta`, compatível com o plugin Spaced Repetition.

O que significa MTTD?::Mean Time To Detect, tempo médio para detectar um incidente.
O que significa MTTR?::Mean Time To Respond ou Recover, tempo médio para responder ou recuperar.

## Cartões de múltiplas linhas

???

## Boas práticas
- Uma ideia por cartão.
- Perguntas que exijam recordação ativa, não reconhecimento.

## Erros comuns
- Respostas longas demais.
- Cartões que dependem de contexto externo.
