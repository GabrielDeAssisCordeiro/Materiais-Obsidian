# Livros Cursos e Comunidades - Cpp

> [!question] Verificar na documentação oficial
> Edições, preços e links mudam. Confirme a edição mais recente (preferencialmente cobrindo **C++20 ou superior**) antes de comprar e confira se os sites ainda estão ativos.

## Referências essenciais (gratuitas)

| Recurso | Para quê |
|---|---|
| **cppreference.com** | Referência da linguagem e da biblioteca padrão (a principal) |
| **isocpp.org** | Notícias, FAQ oficial, *Core Guidelines* |
| **C++ Core Guidelines** (github.com/isocpp/CppCoreGuidelines) | Boas práticas ([[Core Guidelines]]) |
| **learncpp.com** | Tutorial gratuito e completo, ótimo para iniciantes |
| **Compiler Explorer** (godbolt.org) | Ver assembly e testar compiladores ([[Compiler Explorer]]) |
| **cppinsights.io** | Mostra o que o compilador "enxerga" (lambdas, templates, `auto`) |
| **Quick Bench** (quick-bench.com) | Microbenchmarks online |
| **Rascunhos do padrão** (eel.is/c++draft, open-std.org/jtc1/sc22/wg21) | Texto normativo e *papers* do comitê |
| **Documentação do compilador** | GCC, Clang, MSVC |

## Como estudar

1. **Digite** o código (não só leia). 2. Compile com `-Wall -Wextra -Wpedantic` e sanitizers. 3. Faça os exercícios do vault ([[MOC - Exercícios - Cpp]]). 4. Construa os [[MOC - Projetos - Cpp|projetos]]. 5. Leia código de bibliotecas reconhecidas. 6. Acompanhe o padrão ([[Cpp26 Visão Geral]]).
