# Como usar este vault - Docker

## Abrindo

1. Descompacte o `.zip`.
2. No Obsidian: **Abrir pasta como cofre** e selecione a pasta `Materiais-Obsidian`. Este material fica na subpasta `Docker-Vault` (veja o [[GUIA]]).
3. Abra [[Home - Docker]] (o ponto de partida).

## Como navegar

| Recurso | Para quê |
|---|---|
| **Home** | Mapa principal com links para todas as seções |
| **MOC** (Map of Content) | Índice de cada pasta, com todas as notas |
| **Graph view** | Visualizar as conexões entre notas (filtre por tag, como `#docker`) |
| **Backlinks** | Ver quais notas apontam para a nota atual |
| **Pesquisa** | Procure comandos, erros e termos; use `tag:#projetos` |
| **Canvas** | Mapas conceituais em `Anexos` na raiz do vault (arquitetura, trilha, segurança); veja [[MOC - Anexos]] |
| **Templates** | Modelos em `Templates` para criar suas próprias notas |

## Convenções das notas

- Todas têm *frontmatter* com `tags`, `aliases`, `tipo`, `nivel`, `criado` e `relacionados`.
- Cada nota termina com **Veja também** e, quando útil, **Exercício**.
- Callouts: `[!tip]` dicas, `[!warning]` cuidados, `[!danger]` riscos de segurança, `[!bug]` problemas comuns, `[!example]` exemplos, `[!info]` contexto e `[!question]` pontos a verificar na documentação oficial.

> [!question] Verificar na documentação oficial
> Sempre que encontrar este aviso, confirme o detalhe na documentação oficial antes de usar em produção: versões e recursos mudam.

## Dicas de estudo

- Use o **Graph view** para descobrir conexões; leia por MOC.
- **Pratique** cada comando: ler não basta.
- Adicione suas anotações em notas novas com os [[Template de anotação de estudo]] e ligue-as às existentes.
- Ative (opcionalmente) o plugin comunitário de repetição espaçada para os [[Flashcards de Docker]]; nenhum plugin vem instalado.
