# 🎬 Canais e Cursos

> [!note] Como escolher
> Combine **um curso estruturado** (dá direção) com **um canal/podcast** (dá repertório) e **muita prática** ([[09 - Projetos Práticos/Projeto 01 - Calculadora CLI|projetos]]). Disponibilidade, preços e gratuidade mudam; confirme nas páginas oficiais.

## 🇧🇷 Em português

| Recurso | Tipo | Perfil |
|---|---|---|
| **Curso em Vídeo** (Gustavo Guanabara) — Python | YouTube, gratuito | Bem didático para iniciantes absolutos |
| **Live de Python** (Eduardo Mendes, "Dunossauro") | YouTube | Lives e vídeos de Python do básico ao avançado |
| **Fundação Bradesco / Alura / Rocketseat / DIO** | Plataformas | Trilhas guiadas (algumas gratuitas, outras pagas) |
| **Grupy / PyCon Brasil** (palestras no YouTube) | Eventos | Palestras da comunidade brasileira |

## 🌎 Em inglês — cursos estruturados

| Curso | Onde | Perfil |
|---|---|---|
| **CS50P – Introduction to Programming with Python** | Harvard (edX / YouTube) | Excelente base, com exercícios e certificado opcional |
| **Python for Everybody** | Coursera / freeCodeCamp (YouTube) | Chuck Severance; bom para iniciantes |
| **MIT 6.0001 – Intro to CS and Programming in Python** | MIT OpenCourseWare | Mais voltado a ciência da computação |
| **freeCodeCamp – Python (cursos longos)** | YouTube / site | Gratuito, direto ao ponto |
| **Official Python Tutorial** | python.org | Leitura guiada — veja [[10 - Recursos e Referências/02 - Sites e Documentação Oficial|Documentação]] |
