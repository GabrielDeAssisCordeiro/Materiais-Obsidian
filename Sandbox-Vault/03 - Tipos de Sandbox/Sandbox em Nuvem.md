# Sandbox em Nuvem

Ambientes isolados oferecidos como serviço, sob demanda.

| Serviço | Uso |
|---|---|
| E2B e similares | Executar código de agentes de IA (tipicamente em microVMs) |
| GitHub Codespaces | Ambiente de desenvolvimento em container na nuvem |
| Gitpod/Ona | Ambientes de desenvolvimento efêmeros |
| Any.Run, Hybrid Analysis | Análise de malware online |

> [!question] Verificar na documentação oficial
> Arquitetura interna, nomes comerciais e preços mudam com frequência; confirme com cada provedor.

> [!warning] Dados enviados a terceiros
> Considere LGPD e confidencialidade antes de enviar arquivos ou dados reais a serviços online.
