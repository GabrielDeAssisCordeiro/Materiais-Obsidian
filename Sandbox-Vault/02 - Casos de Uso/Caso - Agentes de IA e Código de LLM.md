# Caso - Agentes de IA e Código de LLM

Modelos de linguagem geram código e agentes executam comandos. A saída de um LLM é **entrada não confiável**, sobretudo quando influenciada por *prompt injection*.

- Execute código gerado em sandbox efêmera, sem credenciais.
- Limite rede e sistema de arquivos ao diretório de trabalho.
- Exija aprovação humana para ações destrutivas.
