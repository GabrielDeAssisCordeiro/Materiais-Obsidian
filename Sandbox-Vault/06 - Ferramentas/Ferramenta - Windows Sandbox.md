# Ferramenta - Windows Sandbox

Ambiente Windows descartável e leve, integrado ao Windows Pro/Enterprise/Education, configurado por `.wsb`. Ideal para abrir arquivos suspeitos rapidamente; **não** é um laboratório de análise de malware completo (sem snapshots persistentes).
