# Ferramenta - Kata Containers

Executa cada pod/container em uma **VM leve**, mantendo a experiência de containers (OCI, Kubernetes) com isolamento por hardware. Pode usar diferentes VMMs (por exemplo, QEMU, Cloud Hypervisor, Firecracker).

> [!question] Verificar na documentação oficial
> Combinações suportadas de VMM, runtime e Kubernetes variam por versão.
