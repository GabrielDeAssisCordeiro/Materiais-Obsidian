# Materiais Obsidian

Coleção de materiais de estudo em português do Brasil, escrita como um vault do [Obsidian](https://obsidian.md) e versionada neste repositório. Cada material fica na sua pasta, com Home, Índice e Trilha de aprendizado próprios, e todos compartilham um glossário, templates e anexos.

## Como usar

- **No Obsidian (recomendado):** clone ou baixe o repositório e use *Abrir pasta como cofre* na pasta raiz. Os links entre notas, os canvases e os templates dependem da raiz.
- **No GitHub:** use as tabelas abaixo para navegar. As notas usam `[[wikilinks]]` e callouts do Obsidian, que o GitHub mostra como texto simples; para ler com formatação e links completos, abra no Obsidian.
- **Nomes acentuados:** para ver os nomes dos arquivos corretamente no terminal, rode `git config core.quotepath false`.

## Convenções

| Tema | Regra |
|---|---|
| Propriedades | `titulo`, `nivel`, `criado`, `tipo`, `tags`, `aliases` e `relacionados`; nomes em português, minúsculos e sem acento |
| `nivel` | `iniciante`, `intermediario`, `avancado` ou `todos` |
| `criado` | Data no formato `AAAA-MM-DD` |
| Nome da nota | Único em todo o vault. Se o nome se repetir entre materiais, acrescente ` - <Material>` (ex.: `Home - Obsidian`) |
| `00 - Início` | Toda pasta de material tem `Home - <Material>`, `Índice - <Material>` e `Trilha de aprendizado - <Material>` |
| Título | Um só H1 por nota, igual ao `titulo` (sem o emoji, se houver) |
| Aliases | Um alias por conceito; não repita o mesmo alias em outra nota |
| Tags | Temas amplos, em minúsculas e sem acento; prefira uma tag de tema a uma tag de uso único |
| Links | Nome curto quando for único; caminho completo a partir da raiz quando houver ambiguidade |
| Glossário | Termo novo entra no assunto e no tópico certos do Glossário |
| Arquivos | Templates em `Templates/` e anexos em `Anexos/`, na raiz |

## Como adicionar um novo material

1. Crie a pasta `Nome-Vault/` na raiz, com subpastas numeradas.
2. Em `00 - Início`, crie `Home - <Material>`, `Índice - <Material>` e `Trilha de aprendizado - <Material>`, com as propriedades padrão.
3. Acrescente uma linha na tabela **Materiais** deste arquivo.
4. No grafo, crie um grupo de cor com a consulta `path:"Nome-Vault/"`.
5. No Glossário, crie uma seção `## Assunto` e os tópicos `###` com os termos do material.
6. Coloque templates novos em `Templates/` e anexos em `Anexos/`, e liste-os em `MOC - Templates` e `MOC - Anexos`.
7. Rode `python scripts/validate_vault.py` e corrija o que ele apontar.

## Validação automática

O script `scripts/validate_vault.py` confere links, nomes e aliases únicos, YAML, H1, valores de `nivel`, canvases, âncoras do glossário e a pasta `00 - Início` de cada material. Ele roda a cada push e pull request pelo workflow `.github/workflows/validate.yml`.

```bash
pip install pyyaml
python scripts/validate_vault.py
```
