# Casos de uso do Rust

| Área | Exemplos de ferramentas e crates |
|---|---|
| CLI | `clap`, `ripgrep`, `fd`, `bat` |
| Web backend | `axum`, `actix-web`, `tokio` |
| WebAssembly | `wasm-bindgen`, `wasm-pack` |
| Embarcados | `embassy`, `embedded-hal`, `no_std` |
| Sistemas operacionais | kernels e drivers experimentais; suporte no Linux |
| Jogos | `bevy` |
| Desktop | `tauri` |
| Infraestrutura | proxies, bancos de dados, runtimes de contêiner |
| Ferramentas de desenvolvimento | compiladores, linters, bundlers |

> [!info] Quando Rust é uma boa escolha
> Quando você precisa de desempenho previsível, baixo consumo de memória, segurança e/ou um único binário fácil de distribuir.

> [!warning] Quando talvez não seja
> Protótipos descartáveis, scripts curtos e domínios onde o tempo de compilação e a curva de aprendizado pesam mais que o desempenho.
