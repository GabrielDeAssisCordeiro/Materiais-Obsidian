# Livros, cursos e comunidades

> [!question] Verificar na documentação oficial
> Links, edições e a existência de comunidades mudam com o tempo. Confirme sempre no site oficial (rust-lang.org/learn) antes de adotar um recurso.

## Documentação oficial (gratuita)

| Recurso | Para quê |
|---|---|
| **The Rust Programming Language** ("The Book") — doc.rust-lang.org/book | o caminho principal para aprender |
| **Rust by Example** — doc.rust-lang.org/rust-by-example | aprender por exemplos executáveis |
| **Rustlings** — github.com/rust-lang/rustlings | exercícios pequenos no terminal |
| **The Standard Library** — doc.rust-lang.org/std | referência da `std` |
| **The Cargo Book** — doc.rust-lang.org/cargo | tudo sobre Cargo |
| **The Rust Reference** — doc.rust-lang.org/reference | especificação da linguagem |
| **The Rustonomicon** — doc.rust-lang.org/nomicon | `unsafe` e o lado sombrio |
| **Asynchronous Programming in Rust** — rust-lang.github.io/async-book | async em profundidade |
| **Rust API Guidelines** — rust-lang.github.io/api-guidelines | design de bibliotecas |
| **Edition Guide** — doc.rust-lang.org/edition-guide | diferenças entre edições |
| **Error codes** — doc.rust-lang.org/error_codes | explicação de cada `E0xxx` |

## Como estudar com eficiência

1. Leia um capítulo do *The Book* e **digite** (não cole) os exemplos.
2. Faça os exercícios de [[MOC - Exercícios - Rust]] e os [[MOC - Projetos - Rust|projetos guiados]].
3. Resolva Rustlings em paralelo.
4. Leia código de crates populares (`ripgrep`, `serde`).
5. Contribua: documentação e issues "good first issue".
