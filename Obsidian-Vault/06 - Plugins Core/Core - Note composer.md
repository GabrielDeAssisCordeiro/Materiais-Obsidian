# Core - Note composer

## Para que serve
Mescla notas e extrai trechos para novas notas.

## Como configurar
- *Extract current selection*: move o texto selecionado para outra nota, deixando link.
- *Merge current file with another file*.
- Opção de template para a nota extraída.

## Exemplo de uso
> [!example] Exemplo
> Extraia uma seção longa para virar nota atômica ([[Notas atômicas]]).

> [!tip] Refatorar notas
> Ideal para dividir notas que cresceram demais.
