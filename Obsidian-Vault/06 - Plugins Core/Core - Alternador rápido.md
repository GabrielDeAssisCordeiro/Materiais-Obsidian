# Core - Alternador rápido

## Para que serve
Abre ou cria notas pelo nome, com busca aproximada.

## Como configurar
- Atalho `Ctrl/Cmd + O`.
- Opções típicas: mostrar anexos, outros tipos de arquivo, apenas notas existentes e aliases.
- Comando de criar nota quando não existe.

## Exemplo de uso
> [!example] Exemplo
> Digite `zet` e abra [[Zettelkasten]].
