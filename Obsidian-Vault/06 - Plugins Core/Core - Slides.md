# Core - Slides

## Para que serve
Transforma a nota em apresentação com `---` separando slides.

## Como configurar
- Comando *Start presentation*.
- Sem opções avançadas.

## Exemplo de uso
> [!example] Exemplo
> Apresentação rápida sobre [[Vault]].

> [!tip] Simples e rápido
> Para decks elaborados, exporte ou use outro app.
