# Core - Graph view

## Para que serve
Exibe o grafo global ou local das notas e links.

## Como configurar
- Global e local; filtros, grupos, exibição e forças.
- Sem configuração em Settings; opções ficam no painel do próprio grafo.

## Exemplo de uso
> [!example] Exemplo
> Grupo com busca `path:"06 - Plugins Core"` colorido.

> [!warning] Desempenho
> Em vaults grandes, use grafo local ([[Desempenho]]).
