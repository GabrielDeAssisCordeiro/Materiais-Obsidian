# Core - Explorador de arquivos

## Para que serve
Mostra a árvore de pastas e notas do vault no painel esquerdo.

## Como configurar
- Criar nota/pasta pelos ícones do topo.
- Ordenar (nome, data de edição/criação).
- *Auto-reveal current file*: destaca a nota aberta.
- Arrastar para mover (links são atualizados se a opção estiver ativa).

## Exemplo de uso
> [!example] Exemplo
> Crie `00 - Caixa de entrada` e arraste notas novas para lá ([[Estrutura de pastas]]).

> [!tip] Explorador opcional
> Quem usa [[Alternador rápido]] e links raramente precisa dele.
