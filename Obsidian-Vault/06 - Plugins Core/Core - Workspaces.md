# Core - Workspaces

## Para que serve
Salva e restaura layouts de painéis.

## Como configurar
- Salvar, carregar e excluir layouts pelo comando ou pelo ícone.

## Exemplo de uso
> [!example] Exemplo
> Layout *Escrita* e layout *Pesquisa*.

> [!tip] Troca rápida
> Atribua [[Hotkeys]] para cada workspace.
