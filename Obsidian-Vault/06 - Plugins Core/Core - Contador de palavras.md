# Core - Contador de palavras

## Para que serve
Mostra a contagem de palavras e caracteres na barra de status.

## Como configurar
- Considera a seleção, se houver.
- Sem opções de configuração relevantes.

## Exemplo de uso
> [!example] Exemplo
> Selecione um parágrafo e veja a contagem dele.

> [!tip] Metas de escrita
> Use para acompanhar metas de texto ([[Fluxo de escrita]]).
