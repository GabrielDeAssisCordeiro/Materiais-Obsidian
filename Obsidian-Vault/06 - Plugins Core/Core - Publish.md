# Core - Publish

## Para que serve
Serviço pago para publicar notas como site.

## Como configurar
- Selecione as notas a publicar.
- Configure domínio, aparência e opções do site.
- Notas não selecionadas ficam privadas.

## Exemplo de uso
> [!example] Exemplo
> Publicar um jardim digital ([[Obsidian Publish]]).

> [!warning] Revise antes
> Comentários e anotações ficam no arquivo; revise o que publica.
