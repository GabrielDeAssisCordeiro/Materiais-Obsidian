# Core - Paleta de comandos

## Para que serve
Executa comandos pelo nome.

## Como configurar
- Atalho `Ctrl/Cmd + P`.
- Fixe comandos favoritos no topo da lista.

## Exemplo de uso
> [!example] Exemplo
> Fixe *Open today's daily note* e *Insert template*.

> [!tip] Descobrir recursos
> Pesquise por palavras-chave para achar comandos novos.
