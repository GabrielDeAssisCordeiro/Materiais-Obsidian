# Core - Busca

## Para que serve
Busca em todo o vault, com operadores e resultados com contexto.

## Como configurar
- Atalho `Ctrl/Cmd + Shift + F`.
- Opções: mostrar mais contexto, explicar termos, recolher resultados e ordenar.
- Busca pode ser salva como [[Marcadores|marcador]].
