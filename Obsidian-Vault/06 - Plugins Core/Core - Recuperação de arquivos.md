# Core - Recuperação de arquivos

## Para que serve
Guarda snapshots locais das notas para restaurar versões antigas.

## Como configurar
- Intervalo de snapshot (padrão da ordem de minutos) e tempo de retenção (padrão da ordem de dias).
- Comando para abrir e restaurar snapshots.

## Exemplo de uso
> [!example] Exemplo
> Restaure a versão de ontem de uma nota alterada por engano.

> [!warning] Não substitui backup
> Snapshots são locais ([[Backup]]).
