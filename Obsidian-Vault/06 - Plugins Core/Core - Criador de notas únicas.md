# Core - Criador de notas únicas

## Para que serve
Cria notas com ID único baseado em data e hora no nome.

## Como configurar
- Formato do prefixo (ex.: `YYYYMMDDHHmm`).
- Pasta e template.
- Comando para criar nota única.
