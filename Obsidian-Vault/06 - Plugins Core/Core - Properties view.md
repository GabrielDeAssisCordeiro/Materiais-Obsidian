# Core - Properties view

## Para que serve
Mostra todas as properties do vault ou as da nota atual.

## Como configurar
- Lista de propriedades com contagem de uso.
- Painel de propriedades do arquivo ativo.
- Renomear uma propriedade para padronizar.

## Exemplo de uso
> [!example] Exemplo
> Descubra se há `categoria` e `tipo` duplicadas e unifique.

> [!warning] Renomear afeta o vault
> Renomear uma propriedade altera todas as notas que a usam.
