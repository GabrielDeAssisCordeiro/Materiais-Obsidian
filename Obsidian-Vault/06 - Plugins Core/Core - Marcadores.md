# Core - Marcadores

## Para que serve
Guarda atalhos para notas, títulos, blocos, buscas e grafos.

## Como configurar
- Painel de marcadores na lateral.
- Grupos para organizar.
- Adicionar pelo menu da nota ou do bloco.

## Exemplo de uso
> [!example] Exemplo
> Marque [[Home - Obsidian]] e uma busca de revisão.

> [!info] Marcadores × Workspaces
> Marcadores guardam itens; workspaces guardam layout.
