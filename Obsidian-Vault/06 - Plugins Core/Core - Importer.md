# Core - Importer

## Para que serve
Importa notas de outros apps.

## Como configurar
- Escolha a fonte (Evernote, Notion, Apple Notes, etc.), selecione arquivos e a pasta de destino.
- Veja o relatório de importação.

## Exemplo de uso
> [!example] Exemplo
> Importar uma exportação de outro app para uma pasta de teste.

> [!warning] Teste primeiro
> Importe para um vault de teste antes de misturar com o principal.
