# Core - Tags

## Para que serve
Painel que lista todas as tags e a quantidade de notas de cada uma.

## Como configurar
- Clique em uma tag para buscar.
- Árvore para [[Tags aninhadas]].
- Alternar ordenação.

## Exemplo de uso
> [!example] Exemplo
> Abra `#status` e veja subtags.

> [!tip] Menos tags
> Se o painel estiver enorme, reduza tags e use links ([[Pastas, tags ou links]]).
