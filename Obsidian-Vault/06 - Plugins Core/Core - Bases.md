# Core - Bases

## Para que serve
Cria visões de banco de dados sobre notas, em arquivos `.base`.

## Como configurar
- Comando para criar Base.
- Edição visual dos filtros e views.
- Também aceita bloco ` ```base ` na nota.

## Exemplo de uso
> [!example] Exemplo
> Tabela de todas as notas com `nivel: avancado` ([[Bases]]).

> [!info] Sem plugin extra
> Bases é um plugin core, sem instalação de terceiros.
