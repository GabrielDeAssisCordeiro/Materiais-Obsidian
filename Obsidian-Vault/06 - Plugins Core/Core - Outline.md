# Core - Outline

## Para que serve
Exibe a estrutura de títulos da nota.

## Como configurar
- Painel na lateral.
- Clique para ir ao título.

## Exemplo de uso
> [!example] Exemplo
> Navegue pelo outline de uma nota longa.

> [!tip] Use títulos
> Títulos coerentes dão um outline útil.
