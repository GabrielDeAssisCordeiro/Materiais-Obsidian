# Interface

A janela do Obsidian tem áreas bem definidas:

| Área | Função |
|---|---|
| **Ribbon** (barra lateral esquerda) | Atalhos de ações: [[Ribbon e barra de status]] |
| **Painel lateral esquerdo** | Explorador de arquivos, busca, marcadores ([[Core - Explorador de arquivos]], [[Core - Busca]], [[Core - Marcadores]]) |
| **Área central** | Abas e painéis divididos com as notas ([[Painéis, abas e janelas]]) |
| **Painel lateral direito** | Backlinks, links de saída, tags, outline, properties ([[Core - Backlinks]], [[Core - Outline]]) |
| **Barra de status** | Contagem de palavras e informações ([[Core - Barra de status do editor]]) |
| **Barra de título/abas** | Navegação entre notas abertas |

## Elementos de uma nota
- **Título** no topo (renomeia o arquivo).
- **[[Properties]]** logo abaixo do título.
- **Corpo** em Markdown ([[Modos de edição e leitura]]).

## Atalhos de navegação
- `Ctrl/Cmd + P` → [[Paleta de comandos]]
- `Ctrl/Cmd + O` → [[Alternador rápido]]
- `Ctrl/Cmd + ,` → configurações ([[Visão geral das configurações]])

> [!tip] Foco
> Você pode recolher os painéis laterais e trabalhar só com a área central.
