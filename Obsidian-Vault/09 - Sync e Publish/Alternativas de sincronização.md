# Alternativas de sincronização

## Sincronização
| Opção | Observação |
|---|---|
| Dropbox / OneDrive | funcionam em desktop; mobile exige configuração |
| Google Drive | integração irregular com vaults |
| Plugin **Remotely Save** | sincroniza via S3, WebDAV e outros |
| Self-hosted LiveSync | solução própria com banco de dados |
| [[Sincronizar com Syncthing]] | P2P gratuito |
| [[Sincronizar com Git]] | histórico completo |

## Publicação alternativa
| Opção | Observação |
|---|---|
| **Quartz** | gera site estático a partir do vault |
| **Digital Garden** | plugin para publicar via GitHub/Netlify |
| Geradores estáticos | Jekyll, Hugo, MkDocs |

> [!warning] Teste conflitos
> Antes de confiar em qualquer solução, crie uma nota em dois dispositivos e veja o que ocorre ([[Conflitos de sincronização]]).

> [!question] Verificar na documentação oficial
> Verifique estado de manutenção e compatibilidade de cada plugin e serviço.
