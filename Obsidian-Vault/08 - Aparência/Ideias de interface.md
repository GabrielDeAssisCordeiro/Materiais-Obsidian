# Ideias de interface

## Combinações populares
| Estilo | Como |
|---|---|
| **Minimalista** | tema Minimal + [[Style Settings]]; ribbon oculto; título inline |
| **Tipo Things** | tema Things, listas limpas e cores suaves |
| **Colorido (Primary)** | tema Primary para diferenciar áreas |
| **Dashboard** | nota inicial com [[Bases]] ou [[Dataview]] e `cssclasses` |

## Dicas
- Oculte o ribbon e a barra de abas que não usa ([[Ribbon e barra de status]]).
- Use [[Workspaces]] para layouts diferentes (escrita, revisão).
- Defina uma nota inicial ([[Home - Obsidian]]) como painel.
- Cores com propósito: tipos de nota, estados.

> [!tip] Comece enxuto
> Um bom tema, uma fonte confortável e poucos snippets já mudam muito a experiência.
