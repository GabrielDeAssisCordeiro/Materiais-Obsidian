# Cheat sheet Markdown

| Elemento | Sintaxe |
|---|---|
| Título | `# H1` … `###### H6` |
| Negrito / Itálico | `**x**` / `*x*` |
| Tachado / Destaque | `~~x~~` / `==x==` |
| Lista | `- item` / `1. item` |
| Tarefa | `- [ ] item` |
| Citação | `> texto` |
| Código inline | `` `x` `` |
| Bloco de código | cerca com três crases |
| Link externo | `[txt](url)` |
| Wikilink | `[[Nota]]` / `[[Nota\|alias]]` |
| Título / bloco | `[[Nota#Título]]` / `[[Nota#^id]]` |
| Embed | `![[Nota]]` / `![[img.png\|300]]` |
| Tag | `#tag` / `#a/b` |
| Comentário | `%%x%%` |
| Nota de rodapé | `[^1]` |
| Callout | `> [!tip] Título` |
| Fórmula | `$x$` / `$$ … $$` |
| Tabela | `\| a \| b \|` |
| Linha | `---` |
