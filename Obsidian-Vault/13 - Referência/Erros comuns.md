# Erros comuns

| Erro | Consequência | Solução |
|---|---|---|
| Organizar demais antes de escrever | paralisia | caixa de entrada ([[Captura, processamento, conexão e saída]]) |
| Muitas tags e níveis de pasta | bagunça | [[Pastas, tags ou links]] |
| Instalar muitos plugins | lentidão e risco | [[Instalando e avaliando segurança]] |
| Mover arquivos fora do app | links quebrados | [[Links não resolvidos]] |
| YAML sem aspas em `:` | propriedades quebradas | [[Sintaxe YAML do frontmatter]] |
| `tag` em vez de `tags` | propriedade ignorada | [[Propriedades padrão]] |
| `#` em tags no YAML | tag errada | [[Tags]] |
| Pipe `\|` em tabela com alias | tabela quebra | [[Tabelas]] |
| Sincronizar com dois serviços | conflitos | [[Conflitos de sincronização]] |
| Confundir sync com backup | perda de dados | [[Backup]] |
| Notas gigantes | difícil de reutilizar | [[Notas atômicas]] |
| Não ter saída | só coleciona | [[Second brain]] |

> [!tip] Antídoto geral
> Mantenha tudo simples e revise o vault regularmente.
