# Atalhos de teclado

Atalhos padrão (Windows/Linux → Mac). Personalize em [[Configurações de Atalhos]].

| Ação | Windows/Linux | Mac |
|---|---|---|
| Paleta de comandos | `Ctrl + P` | `Cmd + P` |
| Alternador rápido | `Ctrl + O` | `Cmd + O` |
| Nova nota | `Ctrl + N` | `Cmd + N` |
| Busca global | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| Graph view | `Ctrl + G` | `Cmd + G` |
| Editar/Ler | `Ctrl + E` | `Cmd + E` |
| Configurações | `Ctrl + ,` | `Cmd + ,` |
| Negrito | `Ctrl + B` | `Cmd + B` |
| Itálico | `Ctrl + I` | `Cmd + I` |
| Inserir link | `Ctrl + K` | `Cmd + K` |
| Marcar tarefa | `Ctrl + Enter` | `Cmd + Enter` |
| Indentar / desindentar | `Ctrl + ]` / `Ctrl + [` | `Cmd + ]` / `Cmd + [` |
| Nova aba | `Ctrl + T` | `Cmd + T` |
| Fechar aba | `Ctrl + W` | `Cmd + W` |
| Buscar na nota | `Ctrl + F` | `Cmd + F` |
| Abrir link em nova aba | `Ctrl + clique` | `Cmd + clique` |
| Abrir ao lado | `Ctrl + Alt + clique` | `Cmd + Option + clique` |

> [!question] Verificar na documentação oficial
> Atalhos podem variar por versão, idioma do teclado e configuração. Confira em **Settings → Hotkeys**.
