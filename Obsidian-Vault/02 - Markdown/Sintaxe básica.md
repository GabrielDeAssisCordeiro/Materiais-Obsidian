# Sintaxe básica

## Títulos
```markdown
# Título 1
## Título 2
### Título 3
```

## Ênfase
```markdown
*itálico* ou _itálico_
**negrito** ou __negrito__
***negrito e itálico***
~~tachado~~
==destaque==
```
> [!info] Destaque
> `==texto==` é uma extensão do Obsidian ([[Sintaxe estendida]]).

## Listas
```markdown
- item
  - subitem
1. primeiro
2. segundo
- [ ] tarefa pendente
- [x] tarefa concluída
```

## Citações e linhas
```markdown
> Citação
---
```

## Links e imagens
```markdown
[texto](https://obsidian.md)
![texto alternativo](imagem.png)
[[Outra nota]]
```
Veja [[Wikilinks e links Markdown]] e [[Embeds]].

## Quebras de linha
Linha em branco separa parágrafos. Uma quebra simples pode ser tratada como espaço, conforme a opção *Strict line breaks* ([[Configurações do Editor]]).

> [!tip] Atalhos de formatação
> `Ctrl/Cmd + B` negrito, `Ctrl/Cmd + I` itálico, `Ctrl/Cmd + K` link.
