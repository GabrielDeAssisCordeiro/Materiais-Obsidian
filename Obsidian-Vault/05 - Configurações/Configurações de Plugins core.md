# Configurações de Plugins core

**Core plugins** são recursos nativos que podem ser ligados ou desligados. Cada um ativo ganha sua própria seção em Settings.

## Sugestão de ativação
| Plugin | Ativar? | Nota |
|---|---|---|
| Explorador, Busca, Alternador, Paleta | Sim | base da navegação |
| Backlinks, Links de saída, Tags, Properties | Sim | conexões |
| Notas diárias, Templates | Sim | rotina ([[Notas diárias]], [[Templates]]) |
| Outline, Marcadores, Contador de palavras | Sim | apoio |
| Graph, Canvas, Bases | Sim | visualização ([[Graph view]], [[Canvas]], [[Bases]]) |
| Recuperação de arquivos | **Sim** | segurança ([[Histórico de arquivos e recuperação]]) |
| Workspaces, Slides, Importer, Web viewer, Gravador | Conforme uso | |
| Sync, Publish | Só se assinar | ([[Obsidian Sync]], [[Obsidian Publish]]) |

A lista dos plugins ativos fica em `core-plugins.json` ([[Pasta .obsidian]]). Este vault já traz um conjunto sensato.

> [!tip] Menos é mais
> Desative o que não usa para uma interface mais limpa e menos distrações ([[Desempenho]]).
