# Configurações de Aparência

| Opção | Efeito |
|---|---|
| **Base color scheme** | claro, escuro ou seguir o sistema |
| **Themes** | escolher e gerenciar temas ([[Temas]]) |
| **Accent color** | cor de destaque da interface |
| **Interface font / Text font / Monospace font** | fontes ([[Fontes e tipografia]]) |
| **Font size** e ajuste rápido | tamanho do texto |
| **Show inline title** | exibe o título dentro da nota |
| **Show tab title bar** | barra de título nas abas |
| **Show ribbon** | mostra ou oculta o ribbon ([[Ribbon e barra de status]]) |
| **CSS snippets** | ativa arquivos `.css` da pasta `snippets` ([[Snippets CSS]]) |
| **Zoom / Hardware acceleration / Translucent window** | opções de janela (variam por sistema) |

> [!tip] Comece pelo básico
> Ajuste esquema de cor, tamanho da fonte e título inline. Só depois explore temas e snippets.

> [!warning] Temas de terceiros
> Temas são CSS; instale apenas de fontes confiáveis ([[Instalando e avaliando segurança]]).
