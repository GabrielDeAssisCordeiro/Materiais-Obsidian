# Visão geral das configurações

Abra **Settings** com `Ctrl/Cmd + ,` ou pelo ícone de engrenagem.

| Seção | O que contém | Nota |
|---|---|---|
| **General** | idioma, conta, atualizações, importação de configurações | [[Configurações por dispositivo ou por vault]] |
| **Editor** | edição, exibição, comportamento | [[Configurações do Editor]] |
| **Files and links** | links, novos arquivos, exclusão, anexos | [[Configurações de Arquivos e links]] |
| **Appearance** | tema, fontes, snippets CSS | [[Configurações de Aparência]] |
| **Hotkeys** | atalhos | [[Configurações de Atalhos]] |
| **Core plugins** | ativa/desativa plugins nativos | [[Configurações de Plugins core]] |
| **Community plugins** | instala plugins de terceiros | [[Plugins da comunidade e Restricted Mode]] |
| Seções de plugins | opções de cada plugin ativo | [[MOC - Plugins Core]] |

> [!info] Nomes na interface
> A interface pode estar em português ou inglês, e as seções mudam ligeiramente entre versões e plataformas (por exemplo, o mobile).
>
> > [!question] Verificar na documentação oficial
> > Se não encontrar uma opção citada aqui, use o campo de busca das configurações e consulte help.obsidian.md.

> [!tip] Busca em Settings
> Use a paleta para abrir uma seção direto ([[Paleta de comandos]]).
