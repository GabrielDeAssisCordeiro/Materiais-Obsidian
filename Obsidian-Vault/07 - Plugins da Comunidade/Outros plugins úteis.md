# Outros plugins úteis

## Para que serve
Panorama de outros plugins populares, para explorar depois de dominar o básico.

## Instalação e configuração
Instale em **Settings → Community plugins → Browse** ([[Instalando e avaliando segurança]]).

| Plugin | Para quê |
|---|---|
| Tag Wrangler | renomear e mesclar tags |
| Natural Language Dates | `@amanhã` vira data |
| Homepage | abre uma nota inicial |
| Day Planner | planejar o dia com blocos de tempo |
| Paste Image Rename | renomear imagens coladas |
| Highlightr | destaques coloridos |
| Smart Connections / Copilot | recursos de IA |
| Map View | notas com localização em mapa |
