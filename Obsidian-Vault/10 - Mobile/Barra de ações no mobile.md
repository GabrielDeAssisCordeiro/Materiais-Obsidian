# Barra de ações no mobile

## Barra de ferramentas do editor
Fica acima do teclado. Em **Settings → Mobile**, configure quais comandos aparecem e a ordem.

Boas escolhas:
- Inserir link, tag e template ([[Templates]]).
- Negrito, lista de tarefas e indentação.
- Comandos de [[QuickAdd]].

## Gestos
- Deslizar das bordas para abrir painéis.
- Puxar para baixo na nota para abrir ações (configurável: [[Paleta de comandos]] ou [[Alternador rápido]]).

## Ação rápida
O botão de ação rápida pode ser configurado para criar nota, abrir a diária ou outro comando.

## Plugin Commander
O [[Commander]] permite adicionar comandos à barra do mobile.

> [!question] Verificar na documentação oficial
> Confirme nomes de menus e gestos configuráveis na versão atual do app.

> [!tip] Menos botões
> Use poucos ícones, só para o que você realmente usa.
