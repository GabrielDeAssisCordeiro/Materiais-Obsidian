# Checklist de configuração inicial

Faça uma vez ao criar um vault novo. Detalhes em [[Visão geral das configurações]].

## Estrutura
- [ ] Criar o vault em local de fácil backup ([[Vault]], [[Instalação e primeiro vault]])
- [ ] Definir pastas mínimas ([[Estrutura de pastas]])
- [ ] Definir pasta de anexos ([[Gerenciamento de anexos]])
- [ ] Definir pasta de templates ([[Core - Templates]])

## Links e arquivos
- [ ] Ativar *Automatically update internal links* ([[Configurações de Arquivos e links]])
- [ ] Escolher formato de link: wikilink ou Markdown
- [ ] Decidir onde criam as novas notas

## Editor
- [ ] Revisar *Default editing mode* ([[Modos de edição e leitura]], [[Configurações do Editor]])
- [ ] Ativar numeração de linhas, se desejar

## Plugins
- [ ] Revisar [[Configurações de Plugins core]]
- [ ] Manter o **Restricted Mode** até precisar ([[Plugins da comunidade e Restricted Mode]])
- [ ] Avaliar segurança antes de instalar ([[Instalando e avaliando segurança]])

## Rotina
- [ ] Ativar [[Core - Notas diárias]]
- [ ] Criar atalhos para ações frequentes ([[Hotkeys]])
- [ ] Definir backup ([[Backup]]) e sincronização ([[MOC - Sync e Publish]])

> [!tip] Menos é mais
> Comece simples. Cada plugin e regra extra aumenta a manutenção.
