# Método PARA

Criado por Tiago Forte, organiza informações por **acionabilidade**:

| Letra | Significado | Pergunta |
|---|---|---|
| **P** | Projetos | Tem meta e prazo? |
| **A** | Áreas | Responsabilidade contínua? |
| **R** | Recursos | Tema de interesse? |
| **A** | Arquivo | Inativo? |

## Em pastas
```text
10 - Projetos/
20 - Áreas/
30 - Recursos/
90 - Arquivo/
```

## Dicas no Obsidian
- Use uma property `status` e `area` para filtrar com [[Bases]].
- Mova projetos concluídos para o arquivo.
- Combine com links: pasta diz *onde*, link diz *sobre o quê* ([[Pastas, tags ou links]]).

> [!tip] Adaptação
> Se PARA parecer pesado, comece só com projetos e arquivo.
