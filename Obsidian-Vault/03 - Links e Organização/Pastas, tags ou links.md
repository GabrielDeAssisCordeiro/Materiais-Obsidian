# Pastas, tags ou links

Três ferramentas, três papéis:

| Ferramenta | Melhor para | Limite |
|---|---|---|
| **Pastas** | Onde a nota **mora**; separar tipos, contextos, arquivo | Cada nota só está em uma pasta |
| **Tags** | **Estado** e **tipo** (`#rascunho`, `#livro`) | Viram bagunça se forem muitas |
| **Links** | **Significado**: relações entre ideias | Exigem esforço de escrita |
| **Properties** | Dados estruturados e filtros ([[Bases]]) | Precisam de padrão ([[Nomenclatura de propriedades]]) |

## Regra de bolso
1. Use **links** para conectar assuntos ([[MOCs]], [[Notas atômicas]]).
2. Use **properties** para metadados consultáveis ([[Properties]]).
3. Use **tags** com moderação ([[Tags]], [[Tags aninhadas]]).
4. Use **pastas** simples ([[Estrutura de pastas]], [[Método PARA]], [[Johnny.Decimal]]).

> [!tip] Pergunte-se
> "Como vou encontrar isso daqui a seis meses?" Se for por tema, link; por estado, tag/property; por projeto, pasta.
