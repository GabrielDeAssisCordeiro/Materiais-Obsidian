# Links não resolvidos

Um link **não resolvido** aponta para uma nota que ainda não existe. No editor aparece com cor diferente.

## É um problema?
Nem sempre. No Obsidian, links para notas futuras são uma técnica: você escreve a ideia e cria a nota depois.

- Clique no link para criar a nota.
- No [[Graph view]], ative a opção de mostrar notas **não criadas** (*existing files only* desligado).
- Há pesquisa por links não resolvidos via [[Busca e operadores]] e consultas ([[Consultas Dataview]]).

## Quando vira bagunça
- Erros de digitação (`[[Zetelkasten]]`).
- Notas renomeadas fora do Obsidian ([[Estrutura de pastas]]).
- Arquivos apagados.

> [!tip] Revisão periódica
> Reserve um momento mensal para resolver ou apagar links pendentes.

> [!warning] Neste vault
> Todo link deve apontar para uma nota existente; links pendentes são sinal de erro.
