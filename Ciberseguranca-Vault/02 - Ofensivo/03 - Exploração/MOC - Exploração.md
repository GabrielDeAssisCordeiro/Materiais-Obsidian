# MOC - Exploração

## Ferramentas
- [[Cobalt Strike]] — Plataforma comercial de red team com C2 (Beacon), engenharia social e movimentação lateral.
- [[ExploitDB]] — Repositório público mantido pela Offensive Security, catalogando exploits e shellcodes documentados.
- [[Metasploit Framework]] — Framework modular para desenvolvimento, teste e execução de exploits, payloads e pós-exploração.
- [[Sliver]] — Framework C2 multiplataforma, open source, mantido pela Bishop Fox, alternativa ao Cobalt Strike.
- [[searchsploit]] — Interface de linha de comando offline para a base de dados do Exploit-DB.
