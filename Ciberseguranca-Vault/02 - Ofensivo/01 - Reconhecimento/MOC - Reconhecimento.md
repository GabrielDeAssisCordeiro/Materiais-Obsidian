# MOC - Reconhecimento

## Ferramentas
- [[Amass]] — Enumera subdomínios e mapeia infraestrutura DNS/ASN de um alvo.
- [[Maltego]] — Visualização gráfica de relacionamentos entre entidades (pessoas, domínios, IPs, empresas) via transforms.
- [[Recon-ng]] — Framework modular estilo Metasploit para automação de reconhecimento web via módulos e APIs.
- [[Shodan]] — Motor de busca indexando banners de serviços expostos na internet (IoT, ICS, servidores).
- [[SpiderFoot]] — Automatiza consultas a mais de 200 fontes OSINT e correlaciona os dados em um único relatório.
- [[theHarvester]] — Coleta e-mails, subdomínios, IPs e nomes de funcionários a partir de fontes públicas.
