# MOC - Web

## Ferramentas
- [[Burp Suite]] — Proxy de interceptação para análise e manipulação de tráfego HTTP/S em testes de aplicações web.
- [[Nuclei]] — Scanner de vulnerabilidades rápido, dirigido por templates YAML comunitários (CVEs, CVEs, misconfig).
- [[OWASP ZAP]] — Alternativa open source ao Burp Suite, com scanner automatizado e proxy de interceptação.
- [[SQLmap]] — Detecta e explora automaticamente vulnerabilidades de SQL injection, incluindo extração de dados.
- [[ffuf]] — Fuzzer rápido para descoberta de diretórios, arquivos, subdomínios e parâmetros ocultos.
