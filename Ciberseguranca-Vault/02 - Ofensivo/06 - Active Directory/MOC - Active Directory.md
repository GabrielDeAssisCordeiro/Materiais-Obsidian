# MOC - Active Directory

## Ferramentas
- [[BloodHound]] — Mapeia relações de privilégio em Active Directory usando grafos, revelando caminhos até Domain Admin.
- [[CrackMapExec]] — "Canivete suíço" para redes AD: validação de credenciais, execução de comando e enumeração via SMB/WinRM. Projeto sucessor ativo: NetExec.
- [[Impacket]] — Coleção de classes Python para construir e manipular protocolos de rede Windows (SMB, MSRPC, Kerberos).
- [[PingCastle]] — Audita a postura de segurança de um domínio AD e gera relatório de risco com mapa de maturidade.
- [[Rubeus]] — Ferramenta para abuso de Kerberos: Kerberoasting, AS-REP Roasting, geração e injeção de tickets.
