# MOC - Cloud Ofensivo

## Ferramentas
- [[CloudSploit]] — Motor de detecção de más configurações em ambientes AWS/Azure/GCP/Oracle Cloud.
- [[Pacu]] — Framework de exploração ofensiva para ambientes AWS: escalonamento de privilégio, persistência e exfiltração.
- [[Prowler]] — Ferramenta de auditoria de segurança e compliance (CIS, PCI-DSS, GDPR) para AWS, Azure e GCP.
- [[ScoutSuite]] — Audita configurações de segurança em AWS, Azure, GCP e outras clouds, gerando relatório HTML navegável.
