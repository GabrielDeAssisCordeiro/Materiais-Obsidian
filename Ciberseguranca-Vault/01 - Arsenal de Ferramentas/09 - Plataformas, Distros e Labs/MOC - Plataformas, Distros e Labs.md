# MOC - Plataformas, Distros e Labs

## Ferramentas
- [[DVWA]] — Damn Vulnerable Web Application: aplicação PHP propositalmente vulnerável para prática de segurança web.
- [[Hack The Box]] — Plataforma online de laboratórios práticos de pentest, com máquinas vulneráveis e desafios de diversas categorias.
- [[Kali Linux (uso dual — plataforma)]] — Referenciado aqui como plataforma base de laboratório; nota completa em [[Kali Linux]], pasta 1.12-Frameworks-e-Distros.
- [[Metasploitable]] — Máquina virtual Linux propositalmente vulnerável, mantida pela Rapid7 (criadora do Metasploit), para prática segura.
- [[Parrot Security OS (uso dual — plataforma)]] — Referenciado aqui como plataforma base de laboratório; nota completa em [[Parrot Security OS]], pasta 1.12-Frameworks-e-Distros.
- [[TryHackMe]] — Plataforma online de treinamento em segurança com trilhas guiadas, voltada especialmente a iniciantes.
