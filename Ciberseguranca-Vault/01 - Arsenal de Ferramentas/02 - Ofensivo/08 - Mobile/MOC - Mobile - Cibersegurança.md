# MOC - Mobile - Cibersegurança

## Ferramentas
- [[APKTool]] — Decompila e recompila arquivos APK, permitindo edição de recursos e smali code.
- [[Frida]] — Toolkit de instrumentação dinâmica para injetar scripts JavaScript em processos nativos e apps móveis.
- [[MobSF]] — Plataforma automatizada de análise estática/dinâmica para apps Android, iOS e Windows.
- [[objection]] — Ferramenta de exploração runtime construída sobre Frida, sem necessidade de jailbreak/root.
