# Kali Linux

> Distribuição Linux baseada em Debian, mantida pela Offensive Security, com centenas de ferramentas de pentest pré-instaladas.

## Como funciona
É uma distribuição Debian customizada que já vem com os repositórios e pacotes de centenas de ferramentas de segurança pré-configurados e organizados em metapacotes temáticos (ex.: `kali-tools-web`, `kali-tools-wireless`), eliminando o trabalho de instalar e configurar manualmente cada ferramenta individualmente.

## Como usar
Pode ser instalada como sistema principal, rodada como máquina virtual (imagens oficiais para VMware/VirtualBox) ou via WSL no Windows; o menu de aplicações organiza as ferramentas por categoria (Information Gathering, Vulnerability Analysis, Exploitation Tools, etc.), facilitando a descoberta de ferramentas por fase do pentest.

## Casos de uso
- Ambiente padrão para engajamentos de pentest e certificações (OSCP)
- Base para laboratórios de treinamento em cibersegurança
