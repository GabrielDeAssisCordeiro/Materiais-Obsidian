# MOC - Deception e Honeypots

## Ferramentas
- [[Canarytokens]] — Gera 'iscas digitais' (documentos, URLs, chaves de API, registros DNS) que disparam um alerta imediato quando acessados.
- [[Cowrie]] — Honeypot de média interação que simula um shell SSH/Telnet para capturar tentativas de invasão.
- [[Honeyd]] — Framework clássico para simular topologias de rede inteiras com hosts e serviços falsos de baixa interação.
- [[T-Pot]] — Plataforma que orquestra dezenas de honeypots diferentes (incluindo Cowrie) em containers, com dashboard unificado.
