# MOC - Hardening e Baselines

## Ferramentas
- [[Ansible]] — Ferramenta de automação de configuração usada para aplicar e manter hardening de forma consistente e versionada.
- [[CIS-CAT (CIS Benchmarks)]] — Ferramenta de avaliação automatizada de conformidade com os CIS Benchmarks (baselines de hardening).
- [[Lynis]] — Ferramenta open source de auditoria de segurança e hardening para sistemas Unix/Linux.
- [[Microsoft Security Compliance Toolkit]] — Conjunto de baselines de segurança recomendadas pela Microsoft para Windows e produtos relacionados, em formato de GPO.
