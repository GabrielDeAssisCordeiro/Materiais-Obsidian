# MOC - Cloud e Container

## Ferramentas
- [[Docker Bench for Security]] — Script de verificação automatizada de boas práticas de segurança para hosts e containers Docker.
- [[Falco]] — Motor de detecção de comportamento anômalo em tempo real para containers e hosts Linux, projeto da CNCF.
- [[Prowler (uso dual — cloud)]] — Referenciado aqui pela ótica de compliance de infraestrutura cloud/container; nota completa em [[Prowler]], pasta 1.9-Cloud-Ofensivo.
- [[Trivy]] — Scanner all-in-one para vulnerabilidades em imagens de container, dependências de código e configuração IaC.
- [[kube-hunter]] — Ferramenta de varredura ofensiva para identificar vulnerabilidades e más configurações em clusters Kubernetes.
